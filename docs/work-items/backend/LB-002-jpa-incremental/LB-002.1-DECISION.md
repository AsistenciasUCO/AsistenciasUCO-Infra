## D1. Composición híbrida

- `AsistenciaRepositorySqlServerAdapter` (JDBC) se conserva intacto: commands + query baseline (rollback/paridad).
- `AsistenciaQueryPersistence`: abstracción **interna de Infrastructure** (no es Application Port) para la query.
- `AsistenciaRepositoryHybridSqlServerAdapter`: query → `AsistenciaQueryPersistence` (JPA); commands → adapter JDBC.
- `SqlServerCoreRepositoryAdapterConfiguration` expone **un único** `AsistenciaRepositoryPort` y elige por selector. Valor desconocido → `IllegalStateException` al arrancar (fail-closed). El `EntityManagerFactory` solo se resuelve con `jpa`.

## D2. Auto-configuración JPA de Boot excluida

`HibernateJpaAutoConfiguration`, `HibernateMetricsAutoConfiguration` y `DataJpaRepositoriesAutoConfiguration` se excluyen en `AsistenciasUcoApplication`. Motivos: (1) el default jdbc no debe construir `EntityManagerFactory` ni exigir SQL Server para arrancar; (2) evita que aparezca un `JpaTransactionManager` que reemplazaría al `JdbcTransactionManager` de los commands. El EMF (`SqlServerJpaAsistenciaQueryAdapterConfiguration`) se declara solo con `jpa`, con `hbm2ddl=none`, `show_sql=false`, validation `none` y el mismo `DataSource`.

`application.yml` añade además `spring.jpa.hibernate.ddl-auto=none` y `spring.jpa.open-in-view=false` como defaults seguros por si la auto-configuración se habilitara en el futuro (hoy son inertes).

## D3. Semánticas preservadas

`presente = Boolean.TRUE.equals(...)` (equivalente a `getBoolean`), `estado` String sin enum/default, `observacion = ""` construida en el mapper, sin ORDER BY, sin filas sintéticas, DTO nulo → `CrosscuttingException` con el mismo texto, error JPA → `DatabaseOperationException` con el mismo texto (sin filtrar excepciones Hibernate/JPA).

## D4. Sin dual execution

En runtime se ejecuta un solo provider por invocación. La doble ejecución existe solo en `AsistenciaQueryJpaParityIT`.

## D5. Excepción de gate aprobada (decisión humana, 2026-09-26)

Resultado: **NOT_GREEN** (6 fallos: `SqlStoredProcedureContractIT` ×3, `GrupoRepositorySqlServerIT` ×2, `UsuarioPasswordHashSqlServerIT` ×1).
