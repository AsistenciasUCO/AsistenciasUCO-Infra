# LB-002.0 — DECISION

## D1. Naturaleza de LB-002.1

**LB-002.1 IS A PERSISTENCE TECHNOLOGY MIGRATION.**
**LB-002.1 IS NOT AN AUTHORIZATION ARCHITECTURE MIGRATION.**

El piloto JPA de query:

- NO usa `uv_auth_*`.
- NO establece `SESSION_CONTEXT`.
- NO modifica `InstitutionalScopePort`.
- NO propaga usuario ejecutor al Repository/DTO solo para adoptar RBAC de DB.
- NO modifica roles ni ownership.

Autorización preservada AS-IS: `HTTP Security → Application Use Case → InstitutionalScopePort → Repository`.

## D2. Vistas del piloto

`AsistenciaRepositoryPort.consultarAsistenciasPorGrupo(...)` seguirá obteniendo información equivalente a la JDBC actual desde las vistas congeladas `dbo.uv_detalle_asistencia`, `dbo.uv_asistencia`, `dbo.uv_estudiante_grupo`.

No se usa `uv_auth_asistencia` porque: (1) LB-002.1 no migra autorización; (2) no hay capa auth equivalente completa para toda la query; (3) `SESSION_CONTEXT` introduce lifecycle por conexión/pool; (4) mezclar ambas variables impediría aislar JDBC → JPA.

## D3. SESSION_CONTEXT

Constraint arquitectónico conocido: es estado de la conexión física. La DB garantiza vistas auth fail closed y restauración del contexto previo en su consumidor paginado, pero el backend no lo usa incidentalmente en LB-002.1. Una adopción futura requiere work item independiente que diseñe: set, use, restore, limpieza ante excepción, pooling, fronteras transaccionales y tests de fuga.

`STATE: OUT_OF_SCOPE_LB002_1`

## D5. Entorno SQL Server local esperado para LB-002.1

```text
container: sql_server_asistencias
database:  gestionasistenciadb
```

LB-002.0 no ejecuta SQL ni deployment. Precondición (la ejecuta el usuario fuera de esta fase): antes de la parity JPA, `sql_server_asistencias` debe tener desplegado el freeze DB actual y `test_summary.ps1` debe haber dado PASS. No se documentan credenciales.

## D6. Extensiones DB post-freeze

`uv_auth_*`, `ufn_obtener_usuario_ejecutor_contexto`, `ufn_obtener_perfil_usuario_contexto`, `usp_establecer_contexto_usuario_ejecutor`, `usp_consultar_grupos_paginado`: `KNOWN / DOCUMENTED / NOT_CONSUMED_BY_LB-002.1`. No adoptadas.

## Fuera de esta decisión

Cambios a puertos, DTO, OpenAPI, `src/**` y DB: no requeridos ni realizados.
