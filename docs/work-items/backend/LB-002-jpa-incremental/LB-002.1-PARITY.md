## Semánticas certificadas contra SQL Server real

- **UUID**: `uniqueidentifier` → `UUID` exacto en los 4 campos (Hibernate 7.2.12 + mssql-jdbc); `grupo` de cada fila == grupo solicitado; `sesion` == sesión del filtro.
- **Boolean**: `da.asistio` (`bit NOT NULL`) → `presente` igual a JDBC en filas true/false. **NULL boolean: `NOT_OBSERVED`** — la columna es `NOT NULL` y las vistas usan INNER JOIN; el mapper es defensivo (`Boolean.TRUE.equals`, NULL→false = `getBoolean`) y está probado en unit test.
- **estado**: String tal cual (`AN`, `SJC`, `EX` observados); sin enum ni default.
- **observacion**: `""` exacto en todas las filas.
- **Filtro de sesión**: valor → solo esa sesión; `null` → sin filtro. La expresión `(:sesion is null or a.idSesion = :sesion)` funcionó con UUID nulo y con valor en SQL Server real: **no fue necesario dividir en dos queries**.
- **Missing attendance ≠ AN**: no hay outer join ni filas sintéticas (C1/C2 devuelven `[]`).
- **Orden**: no se añade ORDER BY.
